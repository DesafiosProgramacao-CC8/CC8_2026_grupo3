BIBLIOTECAS NECESSÁRIAS
-----------------------------------------------------------------------------
A biblioteca Pillow é utilizada para abrir imagens e extrair informações que não são fornecidas diretamente pelo pathlib.
No código, ela é importada desta forma:

from PIL import Image

Utilizada para obter informações como:
largura da imagem;
altura da imagem;
formato da imagem;
outros metadados que poderão ser utilizados futuramente.
